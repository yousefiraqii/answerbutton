# زر الإجابة - إضافة Microsoft Word

## 📌 نظرة عامة
إضافة Word تتيح لك تحديد أي سؤال، ثم الضغط على زر "حل السؤال" لتوليد إجابة طبيعية ومهيمنة (Humanized) تعتمد على ملف **PDF** يحتوي على تركاتك وتعليماتك الخاصة.

## 🔧 متطلبات التشغيل
- Node.js (v16 أو أحدث)
- Microsoft Word (2016 أو أحدث، أو Microsoft 365)
- مفتاح API لمزود متوافق مع OpenAI (مثل OpenAI أو Azure أو غيره)

## 🚀 خطوات التشغيل

### 1. تحميل المشروع
انسخ جميع الملفات في مجلد واحد، ثم افتح الطرفية (Terminal) داخله.

### 2. تثبيت الاعتماديات
```bash
npm install
```

### 3. إنشاء الأيقونات
```bash
npm run gen-icons
```

### 3. تشغيل الخادم الخلفي
```bash
npm start
```
ستظهر رسالة تؤكد تشغيل الخادم على المنفذ 3000.

### 4. فتح صفحة الإعدادات
افتح المتصفح على الرابط:  
`http://localhost:3000/settings.html`

### 5. إدخال الإعدادات
- **مفتاح API**: الصقه من مزودك.
- **رابط المزود**: اتركه `https://api.openai.com/v1` إن كنت تستخدم OpenAI الرسمي.
- **النموذج**: اختر مثلاً `gpt-4o-mini`.
- **رفع ملف PDF**: اضغط على منطقة السحب أو اختر ملف PDF الذي يحتوي على تركاتك.
- **اختر اللغة والطول** وأي تعليمات إضافية، ثم اضغط **حفظ الإعدادات**.

### 6. تحميل الإضافة في Word
- افتح Word.
- اذهب إلى **ملف ← خيارات ← الإضافات**.
- من قائمة "إدارة" اختر **"إضافات Word"** ثم اضغط **"انتقال..."**.
- اضغط **"إضافة"** ثم **"استعراض..."** واختر ملف `manifest.xml` الموجود في مجلد المشروع.
- وافق على جميع التحذيرات.

### 7. استخدام الإضافة
- في Word، حدد أي سؤال (نص).
- من تبويب **الصفحة الرئيسية (Home)**، ستجد مجموعة جديدة باسم **"حل السؤال"**، اضغط على الزر.
- ستظهر رسالة "جارٍ إعداد الإجابة…" ثم تُستبدل بالإجابة النهائية المستندة إلى ملف PDF الخاص بك.

## ⚠️ ملاحظات أمان
- مفتاح API يُحفظ محلياً في ملف `settings.json`، وهذا الملف مُستبعد من Git تلقائياً.
- لا يتم إرسال المفتاح إلى أي جهة خارجية سوى مزود API الذي تحدده.

## 🧪 اختبار سريع
يمكنك اختبار الاتصال بالخادم عبر متصفحك بفتح:  
`http://localhost:3000/api/settings`  
وسترى الإعدادات (بدون المفتاح).
